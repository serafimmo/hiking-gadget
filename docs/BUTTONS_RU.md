# Hiking Gadget v2 — что делают кнопки на каждом экране

Таблица сгенерирована командой `hg_render --bindings --lang ru` из тех же привязок, которые исполняет прошивка, поэтому всегда совпадает с ней. Руками не править: `tools/build.sh docs`. Английская версия: [BUTTONS.md](BUTTONS.md).

Как читать:

- действие срабатывает в момент нажатия; «(при отпускании)» — только после отпускания, потому что у этой кнопки есть ещё действие по удержанию;
- **жирным** — действие по удержанию и сколько секунд держать;
- «с повтором» — при удержании действие повторяется и ускоряется;
- [ТЕКСТ] — надпись рядом с кнопкой на экране; «при удержании» — надпись появляется, пока кнопку держат;
- «—» — кнопка на этом экране ничего не делает.

Общие правила:

- Пока экран погашен или притушен, первое нажатие любой кнопки только включает экран; больше это нажатие ничего не делает.
- Сигнал таймера снимается любой кнопкой; это нажатие тоже больше ничего не делает.
- Кнопка, зажатая дольше 10 с, отключается до отпускания и показывает карточку KEY STUCK; остальные кнопки работают.
