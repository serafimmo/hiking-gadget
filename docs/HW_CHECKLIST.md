# Проверка Hiking Gadget v2 на железе

Шаги идут от дешёвых к дорогим (SPEC §11). В колонке «Результат» пишите **Прошло / Не прошло / Не проверялось**. «Не проверялось» — это не «не помогло»: если шаг пропущен, так и пишите. В «Цифры» записывайте то, что просит шаг. Сам отчёт о загрузке (шаг 1) лучше скопировать целиком.

| № | Что сделать | Что должно быть | Если не так | Результат | Цифры / заметки |
|---|---|---|---|---|---|
| 1 | Прошить (README §2), открыть Serial Monitor | За 2 с приходит отчёт о загрузке, **целиком** до `=== ready ===` | Ошибка сборки про «USB CDC On Boot» → меню Tools; тишина → RESET; отчёт оборван → сообщить (проверка вывода §7.3) | | |
| 2 | Посмотреть на экран после прошивки | Заставка, потом Home со временем ≈ времени сборки и меткой `SYNC?`; текст не вверх ногами | Вверх ногами → `kOledFlip = true`; картинка сдвинута на 2 px / мусор справа → `kOledController = Sh1106`; время сильно не то → IDE не пересобрала `.ino` или пояс ПК ≠ MSK | | |
| 3 | Settings › Diagnostics › Buttons; нажимать `^`, `v`, `#`, `*` по одной | Строки `K1 UP`, `K2 DOWN`, `K3 HASH`, `K4 STAR` считают нажатия в этом порядке | Записать, какая K загорелась на какой символ; правится только `kKeyPins` | | |
| 4 | Там же: квадратик на правом краю загорается рядом со своей кнопкой? | Квадраты `v` и `#` на уровне своих кнопок; `^` и `*` — подсказки в углах | Записать «квадрат на N px выше/ниже кнопки» для `v` и `#` → поправка `kCapHashY`, `kCapStarY`, `kRailSlotY` | | |

| 9 | Diagnostics › Sensors строка DRDY; страница 4 при вращении | QMC5883L ≈ 50 фронтов/с RISE; HMC ≈ 15/с FALL; QMC5883P `NO PIN`; X/Y/Z меняются плавно, OVF 0 | Записать строку DRDY; DRDY = 0 допустимо (работаем опросом) | | |
| 10 | Compass › `#` (калибровка): держать **ровно**, два медленных оборота | Кольцо заполняется, `Ready`, `*` SAVE → `GOOD`/`OK` | Записать качество %, поле µT и были ли `Keep level!` / `Metal near?` | | |

| 17 | Яркость Low / Mid / High дома ночью и на солнце | Три заметно разных уровня; Low читается ночью | Сообщить; настройка §3.7 | | |
| 18 | Читать экран на улице на вытянутой руке | Дата, единицы, подписи, сообщения читаются | Записать, какой текст слишком мелкий | | |

## Что прислать после проверки

1. Отчёт о загрузке из шага 1 (целиком).
2. Эту таблицу с заполненными колонками «Результат» и «Цифры».
3. Если что-то не прошло: вывод `LOG DUMP` сразу после проблемы и фото экрана.

## Открытые вопросы `[HW?]`: ответ даст только железо

Всё ниже в прошивке сделано по документации и фотографиям, но на плате не проверялось (SPEC §12). Каждый вопрос закрывается своим шагом таблицы выше; до этого он остаётся открытым, даже если «вроде работает».
